# Project Name

## Folder conventions
- `00_admin/` — internal objects, gitignored (correspondence, config)
- `01_docs/` — session notes, AI prompts, metadata, references, NOTES.md
- `02_writing/` — source .md files and rendered docx/pdf outputs
- `03_data/` — raw (never modified) and processed data
- `04_scripts/` — r/ and python/ scripts
- `05_outputs/` — figures, tables, rendered documents
- `06_archive/` — completed work, retained for reference
- `99_sandbox/` — triage area, gitignored
- `scratch.md` — session scratchpad, gitignored
- `WATERSHED.md` — parked decisions and unresolved questions
